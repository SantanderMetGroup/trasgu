# Changelog

All notable changes to Trasgu are documented in this file.

## 0.1.1 - 2026-08-28

### Changed

- Rename the Chimera store configuration field from `trasgu_url` to
  `chimera_url`, retaining the former name as a deprecated alias.
- Correct the documented download size of the eight-dimensional Chimera
  store.
- Add citation metadata and DOI references for the software and its
  accompanying experimental data.
- Add the curated SoftwareX experiment packaging workflow, derived results,
  figures, and execution provenance.
- Exclude the non-public third-party ship-wake observations and row-level
  pseudo-observations from the public repository and data package.

## 0.1.0 - 2026-08-05

- First public release of Trasgu.
