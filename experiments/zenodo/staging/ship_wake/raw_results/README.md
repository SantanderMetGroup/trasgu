# Representative raw result chunk

`fit_chunk_0067_4000000.csv.gz` is the gzip-compressed, byte-preserving copy
of one output chunk from the exhaustive ship-wake fit. The uncompressed file
has 4,000,000 rows, no header, and SHA-256
`c6acbf1db281905e186701f64616c00aad1c6b00dfc44d18aa72e7d3d4703d60`.

The three comma-separated columns are:

1. `vine_id`: zero-based Chimera matrix identifier;
2. `n_parameters`: number of fitted pair-copula parameters;
3. `aic`: Akaike information criterion returned by the fit.

The chunk covers vine IDs 268,000,000 through 271,999,999. It is provided as
a representative raw artifact, not as the complete exhaustive output.
