# Ship-wake execution snapshot

These files preserve the workflow configuration used for the reported
ship-wake execution. `Snakefile` was recovered from Snakemake's source cache;
all nine cached copies were byte-identical and match the repository copy at
package assembly time (SHA-256
`0f3603d32ea77de504dccaa4abefc098952dfc6a304ce306911a0094fb038346`).

The snapshot is a provenance record, not a portable configuration. It retains
the original GPFS Chimera path and IFCA SLURM resources. Adapt those values to
the target infrastructure before rerunning the experiment.
